# Real-Account Acceptance Testing Checklist

This document tracks the manual acceptance testing of each integration adapter against a real, live account as mandated by `PHASE2_SPEC.md`.

## Instructions
1. Run the test harness for a given integration: `python tests/acceptance/real_account_harness.py --adapter <adapter_id>`
2. Provide an ephemeral access token via environment variable when prompted. **NEVER STORE REAL CREDENTIALS**.
3. Review the output generated by the harness.
4. Update the corresponding section below.
5. Allowed Status values: 
   - `[PASS]`
   - `[FAIL]` 
   - `[BLOCKED BY EXTERNAL CONFIGURATION]` (Use ONLY if the integration is blocked due to external permissions/configuration, e.g., OAuth scopes denied by the provider. Do NOT falsely mark a blocked integration as PASS).
