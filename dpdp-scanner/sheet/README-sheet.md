# The Google Sheet side

Paste `Code.gs` into Apps Script (Extensions > Apps Script) and follow the
main README from Part 2.

Four tabs get created automatically by "DPDP Scan > Set up the sheets":

| Tab | What goes in it |
|---|---|
| **Domains** | You paste website addresses here. Column A only. |
| **Results** | One row per website scanned. The stage is column D. |
| **Trackers found** | Every individual tracker, one row each. |
| **Log** | What happened and when, for troubleshooting. |
